# CodeAlpha Internship – Submission Report

## Project Title
**E-Commerce Product & Customer Review Analytics**

## Tasks Completed

### 1. Web Scraping
Collected structured book/product information from a public educational demo website using Requests and BeautifulSoup.

### 2. Exploratory Data Analysis
Analyzed an e-commerce dataset for data quality, distributions, trends, correlations, outliers, category performance and brand performance.

### 3. Data Visualization
Created six visualizations to communicate revenue, sales, ratings, sentiment, trends and price-rating relationships.

### 4. Sentiment Analysis
Applied NLP sentiment scoring to customer reviews and classified them as Positive, Neutral or Negative.

## Conclusion
The project demonstrates an end-to-end Data Analytics workflow from data acquisition to business insights and NLP.

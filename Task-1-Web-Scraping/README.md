# Task 1 – Web Scraping

## Objective
Extract structured product information from a public web page using Python.

## Tools
- Python
- Requests
- BeautifulSoup
- Pandas

## Data Collected
- Book title
- Price
- Rating
- Product URL

## How to Run
```bash
pip install -r ../requirements.txt
python web_scraping.py
```

The script collects multiple pages from the educational demo site **Books to Scrape** and saves `scraped_books.csv`.

## Learning Outcomes
- Understand HTML structure
- Select elements with CSS selectors
- Navigate pages
- Convert scraped records into a Pandas DataFrame
- Export data to CSV

> This project uses a public educational/demo website for scraping practice.

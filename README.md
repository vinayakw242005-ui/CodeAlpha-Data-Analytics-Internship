# CodeAlpha Data Analytics Internship

## E-Commerce Product & Customer Review Analytics

This repository contains the four projects completed for the **CodeAlpha Data Analytics Internship**.

The projects demonstrate an end-to-end analytics workflow:

**Web Scraping → Data Collection → EDA → Data Visualization → Sentiment Analysis**

---

## 📌 Tasks

### Task 1 – Web Scraping
Extract product information from a public educational website using:
- Python
- Requests
- BeautifulSoup
- Pandas

[Open Task 1](./Task-1-Web-Scraping/)

### Task 2 – Exploratory Data Analysis
Explore product, pricing, rating, sales and review data to identify trends, patterns, correlations and anomalies.

[Open Task 2](./Task-2-EDA/)

### Task 3 – Data Visualization
Create business-focused visualizations covering revenue, sales, ratings, sentiment and trends.

[Open Task 3](./Task-3-Data-Visualization/)

### Task 4 – Sentiment Analysis
Classify customer review text into Positive, Neutral and Negative sentiment using NLP techniques.

[Open Task 4](./Task-4-Sentiment-Analysis/)

## 📊 Dataset

The repository includes `ecommerce_products_reviews.csv`, a reproducible project dataset containing 1,000 records with:

- Product ID
- Brand
- Category
- Product Name
- Price
- Rating
- Review Count
- Units Sold
- Review Date
- Review Text
- Sentiment
- Revenue

## 📈 Key Results

- **Records analyzed:** 1,000
- **Total revenue:** ₹21,334,390.06
- **Total units sold:** 19,000+
- **Average rating:** approximately 3.9/5
- Category, brand, sales and sentiment comparisons are included in the analysis.
- Six portfolio-ready visualizations are generated for Task 3.
- NLP-based sentiment results are generated for Task 4.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/CodeAlpha-Data-Analytics-Internship.git
cd CodeAlpha-Data-Analytics-Internship
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Projects

### Task 1
```bash
cd Task-1-Web-Scraping
python web_scraping.py
```

### Task 2
```bash
cd Task-2-EDA
python eda_analysis.py
```

### Task 3
```bash
cd Task-3-Data-Visualization
python data_visualization.py
```

### Task 4
```bash
cd Task-4-Sentiment-Analysis
python sentiment_analysis.py
```

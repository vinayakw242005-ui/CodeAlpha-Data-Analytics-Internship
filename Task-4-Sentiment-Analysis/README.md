# Task 4 – Sentiment Analysis

## Objective
Analyze customer review text and classify reviews as Positive, Neutral or Negative.

## Method
- Text preprocessing
- VADER sentiment scoring when available
- Positive/Neutral/Negative classification
- Category-level sentiment analysis

## Tools
- Python
- Pandas
- NLTK / VADER
- Matplotlib
- Seaborn

## Run
```bash
python sentiment_analysis.py
```

The script generates:
- `sentiment_results.csv`
- `sentiment_distribution.png`
- `sentiment_by_category.png`

## Business Use
Sentiment analysis can help identify customer satisfaction patterns, product issues and opportunities for product or marketing improvements.

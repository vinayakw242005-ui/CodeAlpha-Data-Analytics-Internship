# Task 2 – Exploratory Data Analysis

## Objective
Explore an e-commerce dataset to identify patterns, trends, anomalies and relationships.

## Key Questions
1. Which category generates the highest revenue?
2. Which brands sell the most units?
3. How are product ratings distributed?
4. Is there a relationship between price and rating?
5. Are there potential outliers?
6. What is the customer sentiment distribution?

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Run
```bash
python eda_analysis.py
```

The analysis includes data-quality checks, descriptive statistics, category/brand analysis, IQR-based outlier detection, correlation analysis and visual exploration.
